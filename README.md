# PAPAGEDON AEI — Audio Experience Intelligence

Meta Global AI Developer Hackathon entry (Indie Developer Track, "Build for Your World").

Director Mode: up to three inputs — event flyer, live music, crowd camera —
converge through a director agent into one real-time audio-reactive visualizer.

## Origin note

[papagedon.com/app](https://papagedon.com/app) is my pre-existing live product,
an audio-reactive visuals engine used at paid music events in Nigeria.
**Its code is not in this repo.** Everything here was built during the
hackathon building period (27 Oct to 4 Nov 2026) with Meta models only:
Muse Spark, Muse Wonder, Muse Image, Muse Voice Transcribe, SAM 3.1,
Muse Glimmer, Muse Spark Open, and Muse Code.

Originality rules followed throughout:

- All shaders are written new in this repo (`/shaders`). Nothing is copied
  from the existing PAPAGEDON engine.
- Every flyer, audio clip and image used is my own or generated by Meta models.

## How to run

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in a browser
and press **Start visualizer**. MOCK mode needs no keys and makes no API calls.

## Env vars

| Var | Purpose |
| --- | ------- |
| `AEI_LIVE` | `true` enables real Meta API calls; anything else = MOCK (default) |
| `AEI_DIRECTOR_PROVIDER` | `muse-spark` (Meta Model API) or `muse-spark-open` (Baseten open weights) |
| `META_API_KEY` | Meta Model API key (server-side only, never committed) |
| `BASETEN_API_KEY` | Baseten key for Muse Spark Open (server-side only, never committed) |

Copy `.env.example` to `.env` and fill in keys for the LIVE demo (M7).

## Mock vs Live

- **MOCK (default):** all model stubs in `src/meta/index.ts` return local mocks.
  The page runs end to end: mock theme + mock audio -> director -> example shader.
- **LIVE (`AEI_LIVE=true`):** stubs call the real clients. Clients are
  server-side only (`src/meta/metaClient.ts`, `src/meta/basetenClient.ts`) and
  are reached exclusively through API routes under `src/app/api/`.

## Cost rules

Mock by default, cache everything, never call a model per frame, throttle and
batch. Real API calls happen in exactly these places, all server-side:

| Call site | Model | When |
| --- | --- | --- |
| `extractTheme` | Muse Spark (vision) | once per event flyer (M2) |
| `generateTexture` | Muse Image | once per event (M5) |
| `transcribeChunk` | Muse Voice Transcribe | rolling 10-30s chunks (M4) |
| `analyzeMusic` | Muse Spark | rolling 10-30s chunks (M4) |
| `segmentCrowd` | SAM 3.1 | one frame every ~3s, optional (M5) |
| `planScene` | Muse Spark or Muse Spark Open (Baseten) | director tick, ~2s+, cached (M5) |

Every response is cached by input hash (`src/meta/cache.ts`) and throttled
(`src/meta/rateLimiter.ts`). The render loop never waits on a model call.
